# AI 视频创作系统：无限画布、固定 Workflow 与 Agent 协作 · v0.2

Owner: Sean。2026-10-07。任务：remote-31356340-f29d-4fd4-9919-e4abac5bf291。

本文依据 Sean 本轮提供的 v0.2 需求整理，是该施工任务的新目标与验收依据。与旧 v1 设计冲突时，以本文及用户原始 v0.2 指令为准。旧文档与提交保留为实现历史，不再限制本阶段三视图范围。

## 1. 产品目标

无限画布是“主数据图 + 动态执行覆盖层”。用户主要在独立 PiWeb 中表达目标；Agent 调用固化的业务 Workflow，自动获取上下文、绑定输入，并把状态、中间产物和结果持续写回画布。画布用于检查、确认和纠正，不以手工编排 ComfyUI 节点为主要交互。

本阶段用两个业务过程验证架构：

- 剧本侧：整本小说导入 → 结构化分章节 → 从章节整理实体 → 逐个确认关键实体。
- 实体侧：参考元素搜集 → 目标形象/概念图候选 → 用户确认正式形象 → 三视图生成并归属实体。

不一次性实现完整视频链路；视频镜头、声音制作、上层跨 Workflow 总编排留待后续。

## 2. 概念与职责

| 概念                     | 职责                                             | 画布表现                                  |
| ------------------------ | ------------------------------------------------ | ----------------------------------------- |
| Project                  | 影片工程，承载小说、章节、场景、实体、资源       | 最高层业务边界                            |
| Chapter / Scene / Entity | 一级长期业务对象；实体含角色、物品、道具、场景等 | 默认展开                                  |
| Resource                 | 图片、文本描述、参考素材、正式形象、三视图等资产 | 归属实体，按需展开；候选图尽量铺开        |
| Workflow Definition      | 固定业务流程的函数定义                           | 不作为普通常驻节点                        |
| Workflow Run             | 一次具体调用，绑定实体、资源及配置               | 运行期轻量覆盖，结束后弱化/折叠，保留来源 |
| Agent Session            | 有目标、连续历史与等待/恢复能力的工作会话        | 协作层与跳转入口，不必是普通节点          |

Agent 理解目标、汇聚上下文、调用 Workflow、绑定输入、推进执行和请求确认；Workflow 提供稳定可测试的业务能力；画布呈现对象、关系、执行状态及结果；用户负责目标表达、关键确认和纠正。

Workflow 是业务流程，CLI/API/Tool/MCP 是调用入口，不能混为一谈：Agent → Tool/API/CLI → Task Workflow → 函数、模型、服务或底层 ComfyUI Workflow。开发期先稳定普通 Tool/API 和 CLI，再考虑 MCP 封装；MCP 不是 MVP 前提。

## 3. 共用能力层与固定业务流程

先以手动操作验证创建实体、更新属性、生成参考/概念图、选择版本、生成三视图等能力；Agent 调用同一套操作串联步骤，不另造一套业务逻辑。

至少提供以下业务入口（名称可在接口设计时调整）：

1. StructureNovel：导入整本原文，建立工程级来源与稳定锚点，生成可检索章节。
2. ExtractEntities：读取结构化章节，整理角色、道具、场景及关系；补充描述保持来源与推断区分，关键项逐个确认。
3. CreateEntity：汇聚实体描述、相关小说与已有素材；搜集/登记参考元素，生成多张概念候选，等待正式形象确认。
4. GenerateThreeView：从已确认形象资源自动绑定输入，生成正面、侧面、背面等视图并写回实体资源。

参考元素搜集的具体来源、三视图底层模板/模型需实查现有能力后确定，不能把目标能力写成已实现。提示词允许固定模板与 Agent 动态生成，作为 Run 的版本化配置/过程记录，不是默认一级节点。

## 4. 主数据图与动态执行覆盖层

长期关系与执行关系分别存储、查询和呈现：

- 长期数据关系：章节包含场景、场景引用实体、实体关联章节、资源属于实体、资源版本与已确认来源。
- 执行关系：某次 Run 绑定的输入、步骤、中间资源、输出，以及 Run 间依赖。运行结束可折叠为历史，不能自动变成长期事实。

支持串行 `实体/资源 → Run A → 中间资源 → Run B → 最终资源` 与并行 `同一输入 → Run A/Run B → 各自结果`。底层共享 GPU 可排队执行，业务并发不等于必须同时占用 GPU。

Run 展示等待输入、执行中、等待确认、完成、失败等业务状态，并可映射更细执行状态。运行时用标记、动态图线、进度图标或动画轻量展示；点击展开输入绑定、参数、步骤、中间结果、日志和输出。结束后弱化/折叠，来源不能删除。

Agent 可修改尚未提交的当前输入绑定，并记录变更；实际提交形成不可变执行快照。提交后的输入调整形成新的版本/子 Run，不能改写已发生的执行历史。

默认展示章节、场景和实体。点击章节聚焦/高亮关联场景与实体；点击实体展开其资源。候选图片尽量铺开。规模增长以缩放、聚焦、过滤和弱化历史保持可读性。

## 5. Workflow Session 与独立 PiWeb

第一阶段以业务 Workflow 为入口，默认一个 Workflow 工作实例对应一个连续 Agent Session，而非所有工程共用一个全局聊天，也不是每个按钮新建一次会话。

进入 Workflow 时按规则汇聚工程/章节/实体/资源引用；用户在 PiWeb 描述本次目标，Agent 动态补充上下文，调用固定流程。引用优先于复制，读取最新版本并记录实际读取版本。Session 有目标、上下文、连续历史，可推进、暂停、等待确认和恢复；明显超范围时提醒切换 Workflow。

无限画布与 PiWeb 是两个独立界面。不重写或嵌入 Agent Chat UI。画布 Workflow 入口、实体和 Run 可携上下文标识跳转，恢复或创建对应 Session；小型状态提示可显示是否工作与输出摘要。Pi Agent Backend 执行后通过业务 API/状态同步写回画布。关联使用 Project/Workflow/Session/Run 引用，不在 URL 暴露能力密钥或复制整段上下文。

## 6. 确认、授权与可靠性

- 第一阶段关键实体逐个确认；未来再扩展批量确认与自动采用策略。
- 候选正式形象由用户确认，确认后 Agent 自动将其绑定到三视图 Run。不得沿用旧版“禁止三视图”或要求用户手工接线。
- 授权可覆盖明确、有限的业务流程及确认后的下游步骤；服务记录范围、目标、版本和消费情况，避免每一步重复手动点按钮。未明确授权的额外生成或无限重试不在范围内。
- 手动 UI 与 Agent 共用事务、校验和幂等操作；未知提交不能自动重投。恢复不能重复生成或重复创建资源。
- 保存来源锚点、读取版本、执行输入快照、Workflow 定义版本、参数、Session/Run 身份、中间产物与输出来源。
- 场景局部状态不覆盖全局身份；动态执行绑定不任意修改长期知识图谱。
- 延续独立私有数据/媒体、共享 ComfyUI 单实例、资源租约和产品 Agent/开发 Agent 身份隔离。精确工作区信任不扩展为默认自动信任。

## 8. MVP 验收

1. 整本小说导入后生成章节节点，章节有可检索正文与来源锚点。
2. 从指定章节提取候选实体和关系，在画布出现；关键项逐个确认为正式实体。
3. 从实体创建 Workflow 进入/恢复独立 PiWeb Session，Agent 自动读取相关小说、实体与资源；用户无需逐项手动拼上下文。
4. Agent 自动绑定输入并启动固定 Concept Run；画布实时呈现轻量状态、中间产物及全部候选图。
5. 用户确认正式形象，决策与版本可追溯。
6. Agent 自动绑定正式形象启动 ThreeView Run，产出正面/侧面/背面等视图并作为实体资源展示。
7. Run 完成后弱化/折叠；点击 Run/资源可追溯输入、Workflow 版本、参数、执行链路和输出。
8. 点击章节聚焦相关场景/实体；点击实体展开资源。长期关系不被执行临时连线污染。
9. Session 在关键确认点等待、确认后继续，刷新/重连恢复同一会话和 Run；幂等与未知提交测试确保不重复执行。
10. 共用操作同时可由手动 UI 与 Agent 调用；串行及并行 Run 关系可验证。共享 GPU 的排队不伪报并发执行。

验收目标是证明“对话表达目标 → Agent 调固定 Workflow → 画布持续呈现 → 用户关键确认/纠正”的闭环，而非先覆盖完整影片生产。

## 9. 保持开放的设计项

Run 结束后默认隐藏/微型来源标记/按时间弱化的具体方式；Run 详情字段及底层 ComfyUI 跳转；布局分区算法；大规模过滤/聚焦；提示词最终资产模型；何时引入跨 Workflow 上层编排 Agent。这些不冒充已定稿；在满足 MVP 和来源可追溯的前提下形成可审阅方案。
