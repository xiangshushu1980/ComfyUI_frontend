## 当前行为

默认总览只画五个步骤卡：场景目标、资产准备、场景布局、渲染结果、检查与问题。卡内包含用途、结果组数量及可用代表图。步骤按折返路径排列，实线箭头及文字表示通用制作顺序，不代表某次执行已经完成或每一步存在已校验依赖。

点击步骤或通过“查看步骤”进入局部视图。每页最多六个结果组围绕步骤中心发散；上一组/下一组翻页，防止自动适配将大量节点缩到不可读。环形间距按节点实际对角线计算，保留原图片比例与现有画布样式/设置。适配会水平居中，并为工具栏和底部提示留出空间。

点击结果组在侧栏查看完整文件/修订列表及原图；点击列表项进入既有原始产物详情，保留原始路径、状态、SHA、JSON 和引用。默认不把技术文件逐一画成节点。中性虚线仅表示结果所属步骤；真实文件引用只在选中结果/文件时显示，且仅连接当前页可见的相关组；跨页引用仍可从原始详情查看。

“只看图片”过滤步骤内的结果组，不将空步骤推断为失败或完成。总览始终保留五个步骤。

## 代码入口

- `src/sean-studio/scenePresentation.ts`：纯显示分组、步骤名称和用途、环形位置计算。
- `src/sean-studio/SceneWorkflowView.vue`：步骤卡、总览/局部切换、分页、组侧栏、关系显示与现有 LiteGraph 绘制。

分组规则：assets 下同一资产目录的预览/记录/修订合为一组；scenes 下同一镜头系列的图片和执行检查分别归组；其余按目录和去掉 `-rNNN` 的相对路径归修订组。排序将较大修订号放前，代表图只是浏览缩略图，不代表被采用。全部原始文件都保留在侧栏。资产准备包含候选、方案和选择记录，不能将其中所有模型称为场景实际使用的模型。
